# Figma 화면 적용

## 기준과 범위

- 디자인: [턱없네 Figma](https://www.figma.com/design/UXLrlxcF0LV0ag6bqVk1RS/?node-id=0-1)
- 최신 코드 기준: `develop`의 `0281e44` (PR #79까지). 개인화 저장 동의(#76), AI 비교 명령(#77), 설명 필요 항목(#78), 종류별 촬영 요령(#79)을 유지한다.
- Django 템플릿과 기존 Vanilla JS/CSS에 적용했다. 별도 React 앱이나 Figma Code Connect 게시 작업은 포함하지 않는다.
- 사용자 결정: 전체 화면 적용, 제보는 5단계, 사진 필수 유지, 운영자 화면은 기존 반려 흐름 사용.
- 모델과 Migration을 추가하거나 변경하지 않는다. 판정 규칙과 숫자 기준은 기존 데이터에 둔다.

## 스타일

공통 변수는 `static/css/common.css`, 지도·상세 전용 배치는 `places/static/places/css/places.css`에 둔다.

| 항목 | 값 |
| --- | --- |
| 주요 색 | `#2855a4` |
| 본문 / 보조 글자 | `#28384b` / `#6e6b65` |
| 따뜻한 배경 / 기본 화면 | `#fbf4e8` / `#ffffff` |
| 연한 파랑 / 초록 / 회색 | `#e9f0fa` / `#e8f2ec` / `#f0ece4` |
| 제목 / 소제목 / 본문 / 보조 | 24 / 18 / 16 / 12px |
| 카드 / 입력·버튼 모서리 | 16 / 12px |
| 모바일 좌우 여백 | 24px |
| 기본 버튼 높이 | 52px (운영자 56px) |

Pretendard와 기존 대체 글꼴을 유지한다. 휴대폰 상태 표시줄은 운영체제가 표시하므로 가짜 시계·배터리 표시를 만들지 않는다. 지도는 실제 카카오 어댑터를 유지하며 불러오지 못할 때 목록·검색·제보를 제공한다.

## 기존 기능과의 연결

- 제보 단계 이동은 같은 폼의 입력을 숨기고 보여 준다. 뒤로 이동해도 파일 입력을 새로 만들지 않는다.
- 시설 전환의 관측값 보존·실패 복구, AI 요청 취소/오래된 응답 무시, 사진 축소 완료 대기를 유지한다.
- 오류 응답에서 사진을 보관한 경우 파일 입력의 `required`를 해제한다. 유효한 서명 사진이 없으면 서버의 사진 필수 검증이 그대로 적용된다.
- AI는 빈 칸만 채운다. 사진만으로 알 수 없는 항목의 ‘설명 필요’ 안내와 추가 설명 입력은 제안 확인 상태에서도 사용할 수 있다.
- 분석 중에는 다음 단계 진행을 막고, 사진을 바꾸면 이전 사진의 늦은 응답과 서명 표를 무효화한다.
- 개인화 동의, 브라우저 저장, 계정 저장·철회, 가본 장소 참고값을 유지한다. 기본값을 그대로 쓰는 경우 ‘내 조건 적용’을 표시하지 않는다.
- 검색의 업종 필터는 개인화 판정에도 동일하게 적용한다. 필터 후 기존 검색 결과 개수 제한을 적용한다.
- 시설 정보는 기존 가게·건물 공용 섹션을 활용한다. 시설 사이 이동 경로를 새로 판정하지 않는다.
- 사진 없는 직접 제보는 만들지 않는다. 사진 수정 요청의 대체 사진은 기존 정책대로 선택이다.
- 반려를 ‘수정 요청’으로 표시하거나 새 보완·재제출 상태를 만들지 않는다. 사유를 작성해 기존 반려 처리로 전달한다.
- 출처·확인일·사장님 정보·신뢰도·확인 중 제보 등 기존 기획의 정보는 유지한다. 이 때문에 상세와 운영자 화면의 길이는 Figma 예시보다 길 수 있다.
- 큰 글씨·키보드 포커스·본문 바로가기·판정 아이콘과 문구를 유지한다. 어려움은 회색이며 점수·순위·어려운 장소 개수 집계는 추가하지 않는다.

## 검증

- Django 전체 테스트: 452개 통과.
- Node JS 테스트: 98개 통과. 단계 이동·사진 필수/보관 사진·처리 대기·0 관측값 보존·오류 단계 복귀·시설 전환 대기·AI 수정 흐름을 포함한다.
- Django 시스템 검사 정상, Migration 변경 없음, diff 공백 검사 통과.
- Windows에서 격리된 SQLite와 QA 계정·합성 사진으로 브라우저 확인: 모바일/PC 지도, 조건 변경과 저장 동의, 이름·주소/업종 검색, 제보 장소 검색·단계 이동, 오류 후 사진 재선택 없는 제출, 모의 AI 제안과 수정, 운영자 검토/반려 패널 및 승인 후 공개 반영, 현재 사진 수정 요청, 내 활동 상태 필터, 알림, 로그인 화면. 새 장소·건물 공용 시설·반려 처리의 서버 흐름은 기존 회귀 테스트도 함께 확인했다.
- 카카오 지도·OAuth와 외부 AI 실호출은 유효한 운영 설정으로 별도 확인이 필요하다. 지도 실패 시 목록과 검색은 확인했다. Docker/PostgreSQL 배포 환경은 이번 로컬 검증에 포함하지 않았다.

QA 로그인 경로·합성 데이터·모의 AI 응답은 레포 밖의 격리된 QA 실행 파일에만 두며 서비스 코드에 포함하지 않는다.
